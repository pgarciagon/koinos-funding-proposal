# Pablo Garcia — Koinos Funding Proposal

Funding proposal for Koinos infrastructure, developer tools, documentation, Vortex validator work, and community support.

**[Read the proposal](PROPOSAL_EN.md)**

The proposed commitment is six hours per week for three months, requesting 50,000 KOIN per month. The document includes the budget, contribution history, planned work, and reference links.

This repository publishes the draft for community discussion. Submission to the [Koinos Fund System](https://kfs.koinscan.com/submit) is a separate step; the repository does not indicate an approved or funded proposal.
